# 自愿支持入口

## 体验与边界

首页邀请卡片位于使用理念之后、页脚之前；密码页的轻入口位于生成器和隐私说明之后。文案为「给工具箱添点心意」，支持作者继续打磨与增添小工具，也认可使用、分享和反馈。

`assets/support.js` 提供共享弹窗，不导入密码模块、不读取表单、生成结果、浏览器存储或剪贴板。生成与复制不打开弹窗，只有主动点击入口才加载收款图片；支持状态只在当前页面内存中存在。打开、切换收款方式和关闭保持工具状态，免费功能与打赏无关。

工具箱盖子与暖光随打开、关闭变化，同一动画进度支持中途转向。动画不检测付款，不建立订单，也不表示付款成功。收款内容立即可用，减少动态效果时直接切换状态。

桌面居中弹窗，窄屏底部卡片。关闭按钮保持可见，支持 Esc、遮罩关闭、焦点循环与返回入口；仅当按下和释放都在遮罩上才关闭，避免滚动或拖拽图片时误触。保存原图按钮位于图片之前，可另开原图；同一部手机可保存后在支付应用中从相册识别。

## 验证

`npm test` 在构建产物的 `/BesTools/` 子路径验证两个入口、收款方式切换、原图下载摘要、完整比例、桌面与 375px / 320px 布局、键盘与焦点返回、快速开合、深色与减少动态效果，以及密码、规则、偏好和剪贴板保持不变。

自动化能核对原图字节、展示与下载操作；支付应用的实际识别和收款主体确认由使用者在真实手机中完成。
